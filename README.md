# DeformForward supplementary material

[Open the DeformForward supplementary page](index.html)

The page includes synchronized future predictions for the 12 PhysCoRe benchmark
scenes and six self-collected recordings, followed by per-recording metrics.
In the repository preview, expand a recording to play its video.

The MP4s cover the scored future segments only. The dimmed image background is
composited for display. Reported metrics use the original scoring inputs.
